# Project Planning Checklist Guide

Use this as the gate before buying materials or cutting anything. Mark each item `[x]` only when the detail is written down (not just “in my head”). Items marked **BLOCKER** should be resolved before the working plan is considered build-ready.

---

## 1. Goals & constraints

- [x] Primary purpose defined — TV wall + storage; DVD/Blu-ray; optional lighting
- [x] Must-haves — plywood encasement, full countertop, upper shelf towers, White Dove, permanent install
- [ ] Budget range (materials + finish + contingency ~10–20%) — tools $200–400 known; wood/paint TBD
- [x] DIY vs. hire-out — fully DIY
- [ ] Target completion / sequencing (weekends only, multi-phase OK?)
- [x] Non-negotiables — permanent box-in; cabinet access for cables; outlet move behind TV

---

## 2. Site survey (the room)

- [x] **BLOCKER** — Wall width **159¼"**; composite built-in **131"**; flanks **14⅛"** each; depths recorded
- [ ] Floor-to-ceiling height at left, center, and right (check for slope)
- [ ] Baseboard / crown / casing sizes and how they meet the built-in
- [ ] Wall type (drywall on studs, plaster, masonry) and stud locations in the bay
- [x] Floor type — wood-look plank; risers sit on finish floor
- [x] Photos: front-on / context / detail / dry-fit stored under `photos/`
- [x] HVAC — ceiling round vent (keep clear of uppers)
- [x] Windows / doors — doorway left, window/sofa right constrain flank treatments

---

## 3. Existing furniture inventory

- [ ] Adjustable feet / leveling capability
- [ ] Back panels: solid, open, or removable? Cable cutouts already present?
- [x] Weight rating — low heat/light gear only (DVD/Blu-ray); no AVR
- [x] Visible faces — concealed by plywood; doors remain operable for access

- [ ] Moisture / exterior wall considerations if applicable

---

## How to run a planning review

1. Walk sections 1–7 with the workup in hand; leave 8–10 blank until layout is locked.
2. Answer the five follow-up questions next (they usually expose missing blockers).
3. Re-check section 12 before calling the plan build-ready.
4. Only then buy sheet goods and schedule cut day.
