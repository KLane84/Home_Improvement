# Project Planning Checklist Guide

Use this as the gate before buying materials or cutting anything. Mark each item `[x]` only when the detail is written down (not just “in my head”). Items marked **BLOCKER** should be resolved before the working plan is considered build-ready.

---

## 1. Goals & constraints

- [ ] Primary purpose defined (TV only, media + storage, speakers, gaming, soundbar, etc.)
- [ ] Must-haves vs. nice-to-haves listed
- [ ] Budget range (materials + finish + contingency ~10–20%)
- [ ] DIY vs. hire-out boundaries (framing, electrical, finish carpentry, painting)
- [ ] Target completion / sequencing (weekends only, multi-phase OK?)
- [ ] Non-negotiables (no wall openings, keep outlets accessible, match existing trim, etc.)

---

## 2. Site survey (the room)

- [ ] **BLOCKER** — Overall alcove / wall bay width, height, and depth (finished dimensions)
- [ ] Floor-to-ceiling height at left, center, and right (check for slope)
- [ ] Baseboard / crown / casing sizes and how they meet the built-in
- [ ] Wall type (drywall on studs, plaster, masonry) and stud locations in the bay
- [ ] Floor type and whether toe-kick / plinth will sit on finish floor or subfloor
- [ ] Photos: front-on, each corner, and any problem spots (outlets, vents, returns)
- [ ] HVAC, returns, radiators, or registers that must stay clear
- [ ] Windows / doors / walkways that constrain depth or projection into the room

---

## 3. Existing furniture inventory

- [ ] **BLOCKER** — Piece list with exterior W × H × D for each unit being framed in
- [ ] Material / construction (IKEA particleboard, solid wood, MDF, etc.)
- [ ] Adjustable feet / leveling capability
- [ ] Back panels: solid, open, or removable? Cable cutouts already present?
- [ ] Weight rating / shelf load if components are heavy (AV receiver, subwoofer)
- [ ] Which faces will remain visible vs. fully concealed by new framing/trim
- [ ] Decision: keep as-is, modify (cut backs, add grommets), or reinforce

---

## 4. Layout & fit

- [ ] **BLOCKER** — Scaled sketch or rough CAD of bay with furniture placed
- [ ] Reveal / reveal gaps around furniture (typical ⅛–¼" planning gap before trim)
- [ ] Scribe / filler panel strategy for out-of-square walls
- [ ] TV location: centered on furniture, centered on wall, or optical center for seating
- [ ] Viewing height: floor-to-center-of-screen (or bottom of screen) for primary seating
- [ ] Clearances: doors/drawers that must open; remote IR/Bluetooth line of sight
- [ ] Depth budget: furniture + face frame + trim vs. walkway / rug / coffee table
- [ ] Upper cabinets / floating shelves / open niches vs. solid panel above TV
- [ ] Symmetry vs. intentional asymmetry documented

---

## 5. Structure & framing

- [ ] Framing method chosen (site-built box surround, face frame over furniture, full carcass)
- [ ] Attachment plan: to studs, to furniture only, or hybrid (and why)
- [ ] Header / ledger above TV if mounting TV to wall or new panel
- [ ] Load path for TV mount (studs or plywood backing plate spanning studs)
- [ ] Soft-close / anti-tip for tall units if they remain freestanding inside the frame
- [ ] Service access: how to remove or slide furniture out later without destroying trim
- [ ] Moisture / exterior wall considerations if bay is on an outside wall

---

## 6. Electrical, AV & low-voltage

- [ ] Inventory of devices (TV, soundbar/AVR, consoles, streaming boxes, sub, LED lighting)
- [ ] Power: existing outlets in bay mapped; any new outlets / dedicated circuits needed
- [ ] Cable paths: behind furniture, through grommets, in chase, or in raceway
- [ ] HDMI / optical / Ethernet runs planned end-to-end
- [ ] In-wall rated cable if any run is inside wall cavities (**code / safety**)
- [ ] Heat / ventilation for enclosed AV gear (vents, open backs, fan?)
- [ ] LED / accent lighting: power supply location, dimming, switch/smart control
- [ ] Permit check: any electrical work that requires a licensed electrician in your jurisdiction

---

## 7. Aesthetics & finish

- [ ] Style target (modern flush, traditional face-frame, shaker, board-and-batten, etc.)
- [ ] Match existing room: paint color, stain, trim profile, door style
- [ ] Visible edges: plywood edge banding, solid wood nosing, or paint-grade MDF
- [ ] Hardware (pulls, hinges) or handle-less design
- [ ] TV treatment: flush recess, slight shadow line, or framed like a picture
- [ ] Lighting mood (warm wash, cove, toe-kick glow) — or none
- [ ] Sample board / mood images linked or stored in `aesthetics.md`
- [ ] Finish sequence: paint before install vs. after scribe/caulk

---

## 8. Materials & cut list (fill after layout locks)

- [ ] Sheet goods list (plywood / MDF thicknesses and sheet counts)
- [ ] Dimensional lumber for framing
- [ ] Trim / casing / base / scribe stock and profiles
- [ ] Fasteners, construction adhesive, shims, caulk, filler
- [ ] Hardware (mounts, hinges, levelers, cable grommets, LED kits)
- [ ] Finish materials (primer, paint/stain, topcoat)
- [ ] Waste factor applied (sheet goods often +10–15%)

---

## 9. Tools & shop readiness

- [ ] Measuring: tape, laser, combination square, level (4' + torpedo)
- [ ] Cutting: circular / track saw, miter saw, jigsaw as needed
- [ ] Fastening: drill/driver, finish nailer or brad nailer
- [ ] Finish: sander, caulk gun, painter’s tools
- [ ] Safety: eye/ear protection, dust mask/respirator for MDF
- [ ] Loan / rental list for anything not owned

---

## 10. Build sequence & risk

- [ ] Dry-fit plan for furniture in the bay before permanent framing
- [ ] Step order drafted in `working-plan.md` (demo → level → frame → power → face → finish)
- [ ] Critical measurements re-checked after first dry-fit
- [ ] Failure modes listed (out-of-square walls, furniture depth too deep, TV too high, heat)
- [ ] Reversibility: what can be undone without major drywall repair
- [ ] Neighbor / household impact (noise, dust, room unusable for N days)

---

## 11. Code, safety & “don’t regret this later”

- [ ] TV mount rated for TV weight + margin; lag into structure, not only drywall
- [ ] No covering HVAC returns or compromising egress
- [ ] Cord management does not pinch power cords or block ventilation slots
- [ ] Fire / smoke considerations if enclosing heat-producing gear tightly
- [ ] Child / pet: tip restraint, sharp corners, cable chew risk
- [ ] Future service: how you replace the TV or AVR without demolition

---

## 12. Documentation completeness (repo gate)

- [ ] `measurements.md` filled with real numbers
- [ ] `aesthetics.md` filled with intent + references
- [ ] Follow-up questions in `FOLLOW-UP-QUESTIONS.md` answered
- [ ] `working-plan.md` updated to “build-ready” with cut list + sequence
- [ ] Photos / sketches linked or stored under this folder
- [ ] Checklist review pass complete — no open **BLOCKER** items

---

## How to run a planning review

1. Walk sections 1–7 with the workup in hand; leave 8–10 blank until layout is locked.
2. Answer the five follow-up questions next (they usually expose missing blockers).
3. Re-check section 12 before calling the plan build-ready.
4. Only then buy sheet goods and schedule cut day.
