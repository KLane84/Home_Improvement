# 02 — Side counters (¾″ plywood)

Stepped counters on the **two side cabinets only**. Center console stays lower (existing top).

## Spec

| Item | Value |
|---|---|
| Qty | **2** |
| Material | **¾″** paint-grade plywood (verify actual thickness — some sheets are 23/32″) |
| Blank size (each) | **27″ W × 16″ D × ¾″** |
| Overhang | **1″** past front of 15″-deep cabinet; sides flush to 27″ carcass (face skin may add later) |
| Finish | Primer + Benjamin Moore White Dove; edge-band exposed edges |

## Why 16″ deep

Cabinet depth ≈ **15″**. Counter = 15″ + **1″** front overhang = **16″**.  
Adjust overhang after dry-fit if doors need more knuckle room.

## Board list

| ID | Piece | Qty | Cut size | Grain note |
|---|---|---|---|---|
| C1 | Side counter blank | 2 | **27″ × 16″ × ¾″** | Prefer grain parallel to 27″ span |

## Nesting on one 4×8 (48″ × 96″)

```
48″
┌──────────┬──────────┐
│ 27×16 #1 │ 27×16 #2 │  ← use 32″ of width if rotated, or:
└──────────┴──────────┘
```

Better nesting (grain along 27″):

```
        96″ (sheet length)
   ┌────────────────────────────┐
16 │  27×16        27×16        │  ← both counters in one strip
   ├────────────────────────────┤
   │  remainder for towers…     │
   └────────────────────────────┘
```

Both counters fit in a **16″ × 54″** region (27+27 with saw kerf). Rest of sheet reserved for [03-shelf-towers](./03-shelf-towers.md).

## Build steps

1. Confirm cabinet width/depth after risers are in place.
2. Cut blanks oversized by ⅛″ if you will flush-trim to face skin later; or cut finished 27 × 16.
3. Edge-band front (and sides if exposed).
4. Drill cable grommet if routing power to cabinet top.
5. Screw from below into cabinet corner blocks / cleats — do not rely on glue alone.

## Not in this guide

- Continuous full-width counter (Path A is **stepped**, sides only)
- Center console top replacement (optional later)
