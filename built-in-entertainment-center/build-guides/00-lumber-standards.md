# Lumber standards (actual sizes)

Use these numbers on all cut lists and CAD. Nominal names are labels only.

## Dimensional lumber

| Nominal | Actual thickness × width | How we use it |
|---|---|---|
| **2×4** | **1½″ × 3½″** | Riser ladder frames **on edge** → finished height **3½″** |
| 1×2 | ¾″ × 1½″ | Optional trim / shelf edge / cleats (later) |
| 1×3 | ¾″ × 2½″ | Optional face trim (later) |

**Important:** A “4″ riser” in early notes meant *about toe-kick height*. Built from a single 2×4 on edge, the true height is **3½″**. Do not plane or shim to 4″ unless you decide to add a skin or second layer.

## Sheet goods

| Spec | Actual thickness | Use |
|---|---|---|
| **¾″ plywood** | **0.75″** (verify; some “¾″” is 23/32″ ≈ 0.72″) | Side counters, tower carcass, shelves |
| Paint-grade / sanded birch or similar | — | White Dove finish |
| 4×8 sheet | **48″ × 96″** | Nesting diagrams assume full sheet |

**Edge banding:** iron-on or solid wood on exposed plywood edges after cut.

## Path A stack heights (sides)

| Layer | Actual | Running AFF |
|---|---|---|
| Floor | 0 | 0 |
| 2×4 riser (on edge) | **3½″** | **3½″** |
| Side cabinet carcass | **30″** | **33½″** |
| ¾″ counter | **¾″** | **34¼″** side counter top |

| Center (no riser) | Actual | AFF |
|---|---|---|
| Console carcass | **~30″** | **~30″** |
| Optional thin cap | TBD | — |

**Step (side top vs center top):** ≈ **34¼ − 30 = 4¼″** (plus any center cap difference).

## Ceiling / tower height (field measure)

```
tower_carcass_height = (floor_to_underside_of_crown) − 34¼″
```

Until L/C/R ceiling is measured, cut lists use a **placeholder** of **96″ FFE** and **~3½″ crown** → underside ≈ **92½″** → tower ≈ **58¼″**.  
**Do not cut tower sides until you measure.**

## Footprints (outer)

| Part | W × D × H |
|---|---|
| Side riser ×2 | **27″ × 15″ × 3½″** |
| Side counter ×2 | **27″ × 16″ × ¾″** (1″ front overhang over 15″ cabinet) |
| Shelf tower ×2 | **27″ × 12″ × (field)** |
